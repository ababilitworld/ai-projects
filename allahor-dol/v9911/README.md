# আল্লহর দল — Interactive eBook

Standalone HTML5, CSS3 and ES6 JavaScript eBook. No build step or internet connection is required.

## Open locally

Extract the ZIP and open `index.html` in a modern browser.

## Project files

- `index.html` — eBook content and semantic HTML5 structure.
- `assets/styles.css` — responsive, print and theme styles. All project classes use the `aod2-` prefix.
- `assets/app.js` — ES6 OOP reader, terminal, appearance, print and image-export controllers.
- `composer.json` — Composer project metadata for repository management.

## Reader terminal

Use the **Terminal** button in the upper-right corner or press `T`. Workspace contains Professional Print, Professional Poster and DSLR Image export. Appearance contains Theme and Typography controls.

## Repository

The project is structured to be committed directly to a GitHub repository. No generated dependency directory is required.
