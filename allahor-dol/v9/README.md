# Allahor Dol eBook — AIT-PSA v9 Generic Terminal

This build uses the terminal architecture and the nine theme palettes extracted from the supplied AIT-PSA v9 source.

Open `index.html`.

Reusable files:
- `assets/terminal/ababil-terminal.css`
- `assets/terminal/ababil-terminal.js`
- `assets/js/terminal-config.js`

Change only `terminal-config.js` to reuse the terminal on another webpage.
