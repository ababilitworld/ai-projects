# আল্লাহর দল — Interactive eBook Terminal

Open `index.html` in a modern browser.

Included terminal groups:
- Workspace
- Appearance
- Interaction
- Navigation
- Notification
- Activity

Features:
- Collapsed menu groups by default
- Light/dark-style theme switching
- Font controls
- Focus and presentation workspaces
- Section navigation
- Recent activity tracking using localStorage
- Toast notifications
- A4 and A5 print commands
- Fully responsive design
