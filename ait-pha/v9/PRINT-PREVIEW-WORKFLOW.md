# Print Preview Workflow

The main Print Workspace now uses a Preview-first workflow.

1. Select print configuration.
2. Click **Preview**.
3. Review:
   - selected configuration,
   - recommended browser/printer settings,
   - conceptual imposed sheet preview.
4. Click **Print** from the preview modal.

For Saddle-Stitch A5 Booklet:
- final page size: A5 portrait,
- physical output sheet: A4 landscape,
- duplex: on,
- flip: short edge,
- scale: 100% / Actual size,
- margins: none,
- printer-driver booklet mode: off.
