# Poster Workspace

Terminal path: Workspace → Report → Poster

Features:
- A3/A2/A1/A0, 24×36 inch and custom sizes
- portrait/landscape
- hero, grid, timeline and infographic layouts
- current/selected/all-page source
- minimal/balanced/detailed density
- theme, typography, radius and gap
- bleed, safe margin, printer type, resolution and color intent
- mounting and finishing
- crop marks, registration marks and background control
- preview modal with selected and suggested device configuration
- final Print Poster action
