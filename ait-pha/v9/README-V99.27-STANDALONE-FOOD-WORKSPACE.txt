AIT-PHA v99.27

Fixed flow:
Workspace → Data Center → Data → Food
- Opens a dedicated full-screen Data Center Food workspace.
- It no longer opens any AIT Planner module/page.

Profile → Create/Edit → Available Food
- Add / Manage Food opens the same Data Center Food workspace.
- Every available food item has an Edit icon.
- Edit icon opens the Data Center Food editor for that exact record.
- Food updates notify the profile workspace to refresh its available-food list.

Food workspace:
- Create, edit, copy, delete
- English/Bengali names
- Serving, grams, kcal
- Macro and micronutrient values
- Theme synchronization
