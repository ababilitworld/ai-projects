AIT-PHA v99.20 — AIT Health Planner Module Flow

AIT – Health Planner now opens three primary modules:
1. Profile
2. Food
3. Report

Profile:
- Profile list
- Edit, Copy, Delete and Generate Plan buttons
- Create/Edit workspace contains Identity, Current & Target, Routine and Available Food
- Selected foods are stored inside the profile

Food:
- Shared Bangladeshi food catalogue CRUD
- Create, Edit, Copy and Delete
- Search and category filter
- Removing food also removes it from profile selections

Report:
- Generated report history
- Full-screen report workspace
- Weekly/monthly milestones and daily routine
- Delete report

All workspaces are full viewport and use existing AIT-PHA theme tokens.
