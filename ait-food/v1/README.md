# AIT Baking Manual

Professional Bangla baking manual starter for a Miyako 52L electric oven.

## Included
- Semantic HTML5
- Namespaced CSS3 (`aitb-*`)
- Responsive layout
- Light/dark screen theme
- ES6 OOP JavaScript modules
- Recipe cards
- Search and category filter
- A4 print CSS
- Print page-break controls
- Professional cover and chapter structure
- Oven quick-reference
- 7-day practice plan

## Run
Open `index.html` in a modern browser. For ES modules, a local static server is recommended.

Example:
`php -S localhost:8080`

Then open `http://localhost:8080/`.

## Print
Use the Print button or browser print dialog and select A4 / Save as PDF.
