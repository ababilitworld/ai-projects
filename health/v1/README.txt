হৃদ্‌স্বাস্থ্য রুটিন — Print Instructions

1. index.html Chrome বা Edge-এ খুলুন।
2. A0, A4 অথবা A5 নির্বাচন করুন।
3. "রঙিন প্রিন্ট" চাপুন।
4. Print dialog:
   - Orientation: Portrait
   - Scale: 100%
   - Margins: None
   - Background graphics: ON
   - Headers and footers: OFF
5. Printer edge কাটলে প্রথমে Save as PDF করুন, তারপর Fit to printable area ব্যবহার করুন।

এই সংস্করণে A4 master-page proportional scaling ব্যবহৃত হয়েছে। তাই A0 ও A5-তেও একই pagination ও সম্পূর্ণ border বজায় থাকে।
