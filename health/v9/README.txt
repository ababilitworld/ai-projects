হৃদ্‌স্বাস্থ্য রুটিন — Print Instructions

1. index.html Chrome বা Edge-এ খুলুন।
2. A0, A4 অথবা A5 নির্বাচন করুন।
3. "রঙিন প্রিন্ট" চাপুন।
4. Print dialog:
   - Orientation: Portrait
   - Scale: 100%
   - Margins: None
   - Background graphics: ON
   - Headers and footers: OFF
5. Printer edge কাটলে প্রথমে Save as PDF করুন, তারপর Fit to printable area ব্যবহার করুন।

এই সংস্করণে A4 master-page proportional scaling ব্যবহৃত হয়েছে। তাই A0 ও A5-তেও একই pagination ও সম্পূর্ণ border বজায় থাকে।


Border fix: print artwork is centered inside a safe gutter on every paper size. Do not enable browser margins; keep Scale 100%, Margins None, Background graphics On, Headers/footers Off.


A0 SUPER DSLR JPG EXPORT
-------------------------
1. Internet connection চালু রেখে index.html Chrome/Edge-এ খুলুন (html2canvas exporter CDN থেকে load হয়)।
2. “A0 DSLR JPG” চাপুন।
3. Visible page অথবা সব page নির্বাচন করুন।
4. 300 DPI = 9933×14043 px (~140 MP), 240 DPI = 7946×11235 px।
5. 300 DPI-তে অনেক RAM দরকার; export fail হলে 240 DPI ব্যবহার করুন।
6. প্রতিটি page আলাদা high-quality JPG হিসেবে download হবে।
7. Browser download permission চাইলে Allow multiple downloads দিন।
