V99.2 mobile and print fixes

- Ebook pages automatically fit the phone/tablet width.
- Page aspect ratio and full content are preserved.
- Horizontal webpage overflow is prevented.
- Mobile export dialog is converted to a scrollable bottom sheet.
- Before print, screen zoom/transforms and open menus are removed.
- A4/A5/A0 @page size is applied from the selected paper size.
- After print, the responsive preview is restored automatically.

Mobile print tips:
1. Choose A4 or A5 from Paper size first.
2. Tap Color Print.
3. In the Android/iPhone system print dialog, use the same paper size.
4. Enable background graphics when the browser offers that setting.
5. Use Scale 100% or Fit to page depending on the printer driver.
